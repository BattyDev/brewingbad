# Brewing Bad website

Public static promotional site for battydev.com/brewingbad/. Keep vanilla HTML/CSS/JS with no build step. Publish only site files and approved promotional assets; never add game saves, profiles, logs, credentials, or the Unity project.

After initial repository setup, work on a branch and merge through a pull request. The parent BattyDev.github.io Pages workflow assembles this repository's main branch at /brewingbad/. Do not add a CNAME here or change the parent site's domain.

Keep all artwork based on actual game assets and gameplay captures. Do not substitute generated imagery. Keep the demo coming-soon state until an actual public download is configured in demo-config.js. Bump CSS/JS query versions when those files change.
